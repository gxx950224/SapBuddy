# 类型：接口

**判定**：数据在系统之间进出。

## 取证重点

- 现有接口对象、消息结构、日志与对账表（若有）
- 业务键、增量水位、重复请求处理线索
- 候选技术对象标「待验证」

## 追问方向（交给 grilling）

- 成功标志：传输到达 / 已受理 / 业务完成 各自证据
- 全量 vs 增量、迟到与空批次
- 部分成功原子单元、超时后如何核对再重试
- 对账键、容差、责任方

## 专项检查

- 第3节用 `assets/templates/interface.md`
- 结论层次不得互相替代
- 备选方案与取舍已填写（无则写「无」）

## 归档

- 必出 3.6 样例 JSON，并写 `io-request.json` / `io-response.json`。
- HTML 中原样收录样例，无 logo。
