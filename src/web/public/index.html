怎么打开 / 关闭
方式一：只开网页版（推荐单独用网页时）
命令行输入：sapbuddy web
网页版单独运行，没有聊天。要关，就关掉运行它的黑窗口；想再开，再输入一次命令即可。
方式二：开聊天版（会自动带出网页）
命令行输入：sapbuddy chat（或直接 sapbuddy）
聊天版启动时会自动带出一个网页。这个网页是聊天带起来的，把聊天一关，网页也会跟着一起关。想恢复，重新打开聊天，或改用方式一单独开网页。
小提示
· 每次输入上面的命令，如果 7400 端口还有旧的网页在跑，会自动先关闭旧网页、再启动全新的，不用担心有残留的旧程序。
· 浏览器里的标签页关了没事，只是把"显示窗口"关掉，程序还在后台跑，随时重新打开 http://127.0.0.1:7400 就能用。
