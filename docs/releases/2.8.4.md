# SapBuddy 2.8.4

- 重构 Web 对话流：思考过程、工具调用、提问卡片及流式回答采用统一组件；减少重复信息并支持工具错误摘要。
- 优化流式滚动：在底部跟随输出，上滚暂停跟随，返回底部恢复；重连保留阅读位置，停止操作等待后端确认。
- 完善历史恢复与性能：分页加载、会话摘要缓存、折叠内容按需渲染、加载失败重试，修复重新生成后刷新时的输出错位。
- 增加会话批量管理：跨页选择、日期筛选、JSON 导出、批量删除以及失败项重试；调整清空选择按钮对齐。
- 增加产物文件卡片：预览、下载、打开目录；支持中文下载文件名。
- 增加大模型连接删除功能，移除对应模型配置与凭据。
- 修复窄窗口侧栏折叠导致对话区塌缩的问题，改用覆盖式抽屉；完善设置和文件卡片的窄窗口布局。
- SAP 工具限定访问用户当前启用的连接，禁止自动跨系统查询；改进产物检查指引与拦截提示。

验证：构建成功；203 项测试通过，包含真实浏览器回归测试。
