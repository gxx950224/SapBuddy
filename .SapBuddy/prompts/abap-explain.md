# /abap-explain — ABAP 程序逻辑详解（面向业务顾问）

## 触发条件
- 用户说 解释/说明/详解/讲讲/分析一下 XXX 程序
- 用户说这个程序做什么、逻辑是什么
- 目标用户：业务顾问（非开发人员），需要理解程序的业务逻辑
- ⚠️ 若用户要求"审查/检查代码质量/找 Bug"→ 走 `/abap-code-review`（本流程专注业务解读）

## 前置阅读
- 编码规范：SYSTEM.md
- SAP 工具：直接使用内置 42 个 SAP 工具（`search_abap_objects` / `get_abap_object_lines` / `get_abap_object_info` / `search_abap_object_lines` / `execute_data_query` 等）

## 前置条件
- SAP 连接已配置（`get_connected_systems` 确认可用连接）
- 源码通过**内置 SAP 工具**读取，不依赖任何 MCP 服务器

## 工作流程

### 1. 获取输入
用户说了：$ARGUMENTS

先看其中是否已包含程序/函数名。已有则直接使用，只问缺失的信息。

### 2. 读取源码（智能分步，大程序不全量读）
- 对象类型：报表/程序=`PROG`、函数模块=`FUNC`、类=`CLAS`；对象名不确定先 `search_abap_objects`。
- **先读头部 + 事件块清单**（前 100 行），用 `search_abap_object_lines` 定位 INITIALIZATION / START-OF-SELECTION / FORM / CALL FUNCTION 关键行。
- **再按行区间精读关键段**；程序 > 2000 行必须分步读取，禁止一次全量拉取。

### 3. 存档源码（可选）
默认**不**在本地保存源码；仅当用户明确要求时才保存到 output/ref_<程序名>.abap。

### 4. 解析程序结构（按类型调整重点）
先判断程序类型，再对号解析：
- **报表类**（选择屏幕 + ALV）：输入参数 → 数据读取 → 汇总/计算 → 输出字段
- **接口/批处理类**（无界面）：触发方式 → 数据来源 → 处理 → 结果去向
- **函数/类**：入参 → 读取 → 业务处理 → 返回/异常

通用解析点：
- 选择屏幕：用户输入什么？哪些必填？
- INITIALIZATION / 启动逻辑
- 主逻辑：SELECT 哪些表（表名+字段+条件）？做什么计算/汇总/关联？
- 输出：ALV / 文件 / 接口 / 更新表？
- FORM/方法：每个一句话
- **调用链**：收集被调对象（CALL FUNCTION/PERFORM/CALL METHOD/SUBMIT），
  全部列出一句话作用；**核心被调对象展开 1 层简版逻辑（不递归）**；用户追问再深入。

### 5. 输出逻辑说明（业务语言，结构化）
按以下格式汇报，**用业务语言，避免技术术语**：

`
## 程序概览
- 程序名：<程序名>
- 程序类型：<报表 / 接口 / 批处理 / 函数 / 类>
- 功能一句话：<一句话描述>
- 适用模块：<模块名，不确定标"待确认">

## 业务逻辑流程
1. <用户输入 / 触发方式>
2. <系统从哪取数据>
3. <做什么处理：汇总/计算/转换/关联>
4. <输出什么>

## 数据来源（ALV 报表必填）
| 输出字段 | 来源表 | 来源字段 | 计算逻辑 |
|---------|--------|---------|---------|
| <字段>  | <表名> | <字段>  | <直接取值/SUM/公式> |

## 关键业务规则
- <规则1：过滤条件/汇总维度/状态判断>

## 关联调用（被调对象清单）
| 对象 | 类型 | 一句话作用 |
|------|------|-----------|
| <对象名> | <FUNCTION/CLASS/PERFORM/SUBMIT> | <做什么；核心对象附简版说明> |

## 注意事项
- <运行方式/频率/性能限制>
- <与其他程序的关联>

## 验证建议（帮助业务顾问核对数据）
- <如何验证结果：SE16N 查表核对口径>
- <已知口径/常见误解>
`

### 6. 追问与扩展（可选）
输出后主动提供：
- "需要进一步解释 <某个 FORM/字段> 吗？"
- "需要我实际查一下 <某表> 的数据样例吗？"（`execute_data_query` 跑 3-5 行）
- "需要生成 HTML 版说明文档吗？"（output/<程序名>_LogicExplanation.html）

## 输出契约（完成后汇报）
`
已完成程序逻辑详解：
- 程序：<程序名>
- 功能：<一句话>
- 数据来源：<主要表>
- 关键逻辑：<一句话>
- 关联调用：<N 个，核心为 XXX>
`
