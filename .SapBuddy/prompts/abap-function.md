# /abap-function — ABAP 函数模块开发与修改

## 重要限制
**Agent 不支持创建函数模块**。函数模块必须由用户在 SE37 中手动创建（含接口参数定义）。Agent 只能：
- 读取已有函数模块的源码和接口参数
- 修改函数模块的 ABAP 代码体（不含 `*"` 签名注释块）
- 写入 SAP 并激活

## 触发条件
- 用户需要开发一个新的函数模块 → 用户 SE37 创建空壳 → Agent 写代码
- 用户需要修改已有函数模块的代码

## 前置阅读
- 编码规范：`SYSTEM.md`
- 代码模板与最佳实践：`.pi/skills/abap-function/SKILL.md`
- SAP 工具：直接使用内置 42 个 SAP 工具（`search_abap_objects` / `get_abap_object_lines` / `get_abap_object_info` / `replace_string_in_abap_object` / `abap_activate` 等）

## 工作流程（含确认门禁，⚠ 处必须等用户明确确认）

### 1. 理解需求
用户说了：$ARGUMENTS

从以上内容中提取已有信息：
- 函数模块名：用户是否提到了函数名？
- 操作类型：用户说了"新建/新函数"还是"修改/改"？
- 需求细节：用户提到的参数、表名、业务逻辑等

**已有信息直接确认使用，只问缺失的部分**，不要重复问用户已经给过的内容。

### 2. 确认函数模块名
⚠ 用户确认函数模块名后才能继续。

### 3. 新建 → 用户创建空壳
如果函数模块不存在：
说明"Agent 不支持创建函数模块，请在 SE37 中创建，定义好接口参数后告诉我"。
```
在 SE37 中：
1. 输入函数模块名
2. 定义 IMPORTING / EXPORTING / TABLES / EXCEPTIONS
3. 保存激活
```

### 4. 读取源码获取接口参数
```
内置 `search_abap_objects` 工具（pattern=`<函数模块名>`）确认存在
内置 `get_abap_object_lines` 工具（FUNC `<函数模块名>`）读取源码
```
从 `*"` 注释块提取接口参数。向用户展示：
```
函数：<函数模块名>
IMPORTING：<参数清单>
EXPORTING：<参数清单>
TABLES：<参数清单>
EXCEPTIONS：<异常清单>
```

### 5. 确认表结构和逻辑（输出契约 A）— 必须等用户确认
```
内置 `get_abap_object_info` 工具（TABL `<表名>`）看表结构
```
按以下格式汇报，⛔ 用户明确回复确认前不得做任何代码操作：
```
处理逻辑：
1. 输入校验：<校验逻辑>
2. 数据读取：<查什么表>
3. 业务处理：<核心逻辑>
4. 结果返回：<返回什么>
请确认是否有需要修改的地方？
```

### 6. 生成代码并展示
遵循 `SYSTEM.md` 规范，生成 ABAP 代码体（**不写** `*"` 接口签名注释块），写入 `output/<函数模块名>.abap`，全文展示。
⚠ 用户确认后才能写入 SAP。

### 7. 写入 SAP
传输请求由内置工具自动处理，无需手动指定。
```
内置 `replace_string_in_abap_object` 写入代码体
内置 `abap_activate` 激活
```
激活报错必须修复，同步更新本地文件。同一问题连续失败 3 次 → 停手上报。

### 8. 自我检查（每次完成前必须做）
- 代码体是否在 `*"` 签名注释块之后？（禁止修改接口签名注释）
- 参数名是否符合 SYSTEM.md 前缀规范（IV_/EV_/ET_ 等）？
- **接口参数/字段类型是否全部使用 DDIC 数据元素？（禁止裸内置类型；找不到标准元素时创建 Z 数据元素 + 域）**
- 是否在 output/ 目录生成了本地文件？
- **代码中是否存在硬编码中文文案？（提示/错误必须走消息类或文本元素）**
- **是否已将改动内容发给用户审核并获得批准后才写入？**
- 文件头是否有 "Generated by SapBuddy" 签名？

## 输出契约 B（完成后汇报）
```
已完成：
- 函数模块：<函数名>
- 本地文件：output/<函数模块名>.abap
- 状态：已激活
```
