# /abap-function — ABAP 函数模块开发与修改

## 能力说明
内置工具**支持创建函数模块**：`create_object_programmatically`（FUGR/F 创建函数组、FUGR/FF 创建函数模块空壳）→ `replace_string_in_abap_object` 写入代码体 → `abap_activate` 激活。

## 触发条件
- 用户需要开发一个新的函数模块 → Agent 创建函数组 + 函数模块空壳 → 定义接口参数 → 写代码体 → 激活
- 用户需要修改已有函数模块的代码

## 前置阅读
- 编码规范：`SYSTEM.md`
- 代码模板与最佳实践：`.pi/skills/abap-function/SKILL.md`
- SAP 工具：直接使用内置 42 个 SAP 工具（`search_abap_objects` / `get_abap_object_lines` / `get_abap_object_info` / `create_object_programmatically` / `replace_string_in_abap_object` / `abap_activate` 等）

## 工作流程（含确认门禁，⚠ 处必须等用户明确确认）

### 1. 理解需求
用户说了：$ARGUMENTS

从以上内容中提取已有信息：
- 函数模块名：用户是否提到了函数名？
- 操作类型：用户说了"新建/新函数"还是"修改/改"？
- 需求细节：用户提到的参数、表名、业务逻辑等

**已有信息直接确认使用，只问缺失的部分**，不要重复问用户已经给过的内容。

### 2. 确认函数模块名
⚠ 用户确认函数模块名后才能继续。

### 3. 查重（决定新建/修改路径）
```
内置 `search_abap_objects` 工具（pattern=`<函数模块名>*`）确认是否存在
```
- 不存在 → 走**新建**路径：步骤 4（创建空壳）→ 5 → 6 → 7
- 已存在 → 走**修改**路径：步骤 5 → 6 → 7（跳过创建）

### 4. 新建：创建函数组 + 函数模块空壳
⚠ 创建前必须向用户展示将要创建的对象（函数组名/函数模块名/所属包），用户确认后才创建。

1. **创建函数组**（若不存在）：
   ```
   内置 `create_object_programmatically`（FUGR/F，name=`Z<模块>G<3位编号>`，parentName=包名）
   ```
2. **创建函数模块空壳**：
   ```
   内置 `create_object_programmatically`（FUGR/FF，name=`Z<模块>_FM_<描述>`，parentName=函数组名）
   ```
3. 空壳创建后**立即定义接口参数**（IMPORTING/EXPORTING/TABLES/EXCEPTIONS）：
   - 用 `replace_string_in_abap_object` 在 FUNCTION 语句内写入参数声明
   - 参数命名遵循 IV_/EV_/ET_/ES_ 前缀惯例
   - 参数类型必须用 DDIC 数据元素（禁裸内置类型，见 SYSTEM.md）

### 5. 读取源码获取接口参数（修改路径 / 新建后核对）
```
内置 `get_abap_object_lines` 工具（FUGR/FF `<函数模块名>`）读取源码
```
从 `*"` 注释块提取接口参数。向用户展示：
```
函数：<函数模块名>
IMPORTING：<参数清单>
EXPORTING：<参数清单>
TABLES：<参数清单>
EXCEPTIONS：<异常清单>
```

### 6. 确认表结构和逻辑（输出契约 A）— 必须等用户确认
```
内置 `get_abap_object_info` 工具（TABL `<表名>`）看表结构
```
按以下格式汇报，⛔ 用户明确回复确认前不得做任何代码操作：
```
处理逻辑：
1. 输入校验：<校验逻辑>
2. 数据读取：<查什么表>
3. 业务处理：<核心逻辑>
4. 结果返回：<返回什么>
请确认是否有需要修改的地方？
```

### 7. 生成代码并展示
遵循 `SYSTEM.md` 规范，生成 ABAP 代码体（**不写** `*"` 接口签名注释块），写入 `output/<函数模块名>.abap`，全文展示。
⚠ 用户确认后才能写入 SAP。

### 8. 写入 SAP
传输请求由内置工具自动处理，无需手动指定。
```
内置 `replace_string_in_abap_object` 写入代码体
内置 `abap_activate` 激活
```
激活报错必须修复，同步更新本地文件。同一问题连续失败 3 次 → 停手上报。

### 9. 自我检查（每次完成前必须做）
- 代码体是否在 `*"` 签名注释块之后？（禁止修改接口签名注释）
- 参数名是否符合 SYSTEM.md 前缀规范（IV_/EV_/ET_ 等）？
- **接口参数/字段类型是否全部使用 DDIC 数据元素？（禁止裸内置类型；找不到标准元素时创建 Z 数据元素 + 域）**
- 是否在 output/ 目录生成了本地文件？
- **代码中是否存在硬编码中文文案？（提示/错误必须走消息类或文本元素）**
- **是否已将改动内容发给用户审核并获得批准后才写入？**
- 文件头是否有 "Generated by SapBuddy" 签名？
