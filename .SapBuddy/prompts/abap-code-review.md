# /abap-code-review — ABAP 代码审查

## 触发条件
- 用户说 审查/审计/code review/检查代码/看看代码问题 XXX
- **最高优先级**，覆盖其他流程规则
- ⚠️ 若用户只是要"解释/分析程序做什么"→ 走 `/abap-explain`（本流程专注审查质量）

## 前置阅读
- 审查清单（14 维度）：.SapBuddy/skills/abap-code-review/references/checklist.md
- 审查报告 HTML 模板：.SapBuddy/skills/abap-code-review/assets/report-template.html
- 编码规范：SYSTEM.md（默认 SAP 官方 Clean ABAP）

## 前置条件
- SAP 连接已配置（`get_connected_systems` 确认可用连接）
- 源码通过**内置 SAP 工具**读取，不依赖任何 MCP 服务器

## 工作流程（强制顺序执行）

### 1. 获取输入
用户说了：$ARGUMENTS

先看其中是否已包含程序/函数名。已有则直接使用，只问缺失的信息。

### 2. 读取源码（智能分步）
- 对象类型：报表/程序=`PROG`、函数模块=`FUNC`、类=`CLAS`；对象名不确定先 `search_abap_objects`。
- **先读头部 + 事件块清单**（前 100 行），用 `search_abap_object_lines` 定位关键行。
- **再按行区间精读关键段**；程序 > 2000 行必须分步读取，禁止一次全量拉取。

### 3. 存档源码（可选）
默认**不**在本地保存源码；仅当用户明确要求时才保存到 output/<程序名>.abap。

### 4. ATC 自动检查（客观补充）
调用内置 `run_atc_analysis` 获取代码质量门禁的客观发现（语法/性能/安全/废弃用法），
记录为「ATC 自动发现」并入报告——与 AI 静态走查互补。

### 5. 收集关联对象
留意被 INCLUDE 的程序、配置表、结构等引用对象；用 `find_where_used` 查谁调用本程序（修改影响面）。

### 6. 静态走查
自顶向下逐段核对 references/checklist.md 的 **14 维度**每一项：
- 选择屏幕 → INITIALIZATION → 主逻辑 → 输出
- 同时梳理「程序在做什么 / 怎么做」的脉络
- 若为 ALV 报表，逐字段整理取数逻辑

### 7. 问题定级
每条问题记录：id、严重度（高/中/低）、**位置（FORM/方法/行号，可用 `search_abap_object_lines` 定位）**、
现象、建议修复、**来源（AI 走查 / ATC）**。
严重度配色：红=高，黄=中，蓝=低，绿=OK。
⚠️ 篇幅控制：重点 ≤ 15 条、中危 ≤ 20 条、低危 ≤ 20 条（超出按影响度精选）。

### 8. 生成 HTML 报告
将 assets/report-template.html 复制到 output/ 目录，替换每个 {{TOKEN}} 占位符为真实内容。
在报告底部/脚注添加 "Generated by SapBuddy"。
保存为 output/<程序名>_CodeReview.html。

报告结构（4 个页签）：
1. **程序功能与结构概览**（下方嵌入「代码逻辑详细解析」+ ALV 取数表）
2. **审查发现汇总**（统计 + 汇总表，含 ATC 自动发现）
3. **问题详解**（重点问题 / 中危问题 / 低危与改进建议）
4. **亮点与结论**（亮点 / 结论与修复优先级）

### 9. 交付结果
告知用户报告位置 `output/<程序名>_CodeReview.html`（Web 端产物面板可预览），简要总结发现问题数量。

## 示例（Few-Shot）

**审查发现报告格式示例：**
```
问题 #1（高）｜来源：AI 走查
位置：FORM f_process_data（行 245）
现象：LOOP AT lt_data 前未检查内表是否为空，空表时浪费性能
建议：在 LOOP 前加 IF lt_data IS NOT INITIAL.

问题 #2（中）｜来源：ATC
位置：START-OF-SELECTION（行 88）
现象：SELECT * FROM bkpf 使用了 SELECT *
建议：改为 SELECT bukrs, belnr, gjahr, cpudt FROM bkpf
```

## 输出契约（完成后汇报）
```
已完成代码审查：
- 程序：<程序名>
- 发现问题：X 个（高 X / 中 X / 低 X，其中 ATC 自动发现 Y 个）
- 报告文件：output/<程序名>_CodeReview.html
```
