# ABAP 报表标准代码结构
- **日期：** 2026-07-22
- **对象：** 所有新报表
- **说明：** 报表程序必须使用的代码结构——三段式 ALV + 事件驱动 + 共享 Include。

### 总体框架

```abap
REPORT ZXXXXX MESSAGE-ID ZXX_MSG001.

INCLUDE ZBCX_PUB_CONV_CONS.          "共享常量 Include

TABLES: ...
TYPES: BEGIN OF GTY_OUT.
         ...
         SLBOX      TYPE C,          "选择框必须
       END OF GTY_OUT.

DATA: GT_OUT TYPE TABLE OF GTY_OUT,
      GS_OUT TYPE GTY_OUT.

"自定义按钮常量
CONSTANTS:
  CNS_SAVE   TYPE C LENGTH 10 VALUE '&DATA_SAVE',
  CNS_GEN    TYPE C LENGTH 10 VALUE '&GEN',
  CNS_ADD    TYPE C LENGTH 10 VALUE '&ADD',
  CNS_DEL    TYPE C LENGTH 10 VALUE '&DEL'.

"DATA_CHANGED 事件类
CLASS LCL_EVENT_RECEIVER DEFINITION DEFERRED.
CLASS LCL_EVENT_RECEIVER DEFINITION.
  PUBLIC SECTION.
    METHODS: HANDLE_DATA_CHANGED
      FOR EVENT DATA_CHANGED OF CL_GUI_ALV_GRID
      IMPORTING ER_DATA_CHANGED.
ENDCLASS.

CLASS LCL_EVENT_RECEIVER IMPLEMENTATION.
  METHOD HANDLE_DATA_CHANGED.
    PERFORM FRM_DATA_CHANGED USING ER_DATA_CHANGED.
  ENDMETHOD.
ENDCLASS.

* 选择屏幕定义...

* 事件处理
INITIALIZATION.
AT SELECTION-SCREEN OUTPUT.
AT SELECTION-SCREEN.

START-OF-SELECTION.
  PERFORM FRM_GET_DATA.               "取数
  PERFORM FRM_ALV_DISPLAY TABLES GT_OUT.  "展示
END-OF-SELECTION.
```

### 三段式 ALV（每个报表必须）

```abap
*&---------------------------------------------------------------------*
FORM FRM_ALV_DISPLAY TABLES T_DATA.
  DATA: LT_FIELDCATALOG TYPE LVC_T_FCAT,
        LT_SORT         TYPE LVC_T_SORT,
        LS_LAYOUT       TYPE LVC_S_LAYO.

  PERFORM FRM_SET_LAYOUT CHANGING LS_LAYOUT.
  PERFORM FRM_SET_FIELDCAT TABLES LT_FIELDCATALOG.
  PERFORM FRM_SHOW_ALV TABLES T_DATA USING LT_FIELDCATALOG LT_SORT LS_LAYOUT.
ENDFORM.
```

#### FRM_SET_LAYOUT

```abap
FORM FRM_SET_LAYOUT CHANGING C_LAYOUT TYPE LVC_S_LAYO.
  CLEAR C_LAYOUT.
  C_LAYOUT-BOX_FNAME  = CNS_FD_SLBOX.         "选择框字段名
  C_LAYOUT-ZEBRA      = ABAP_TRUE.
  C_LAYOUT-SEL_MODE   = ZIF_BC_CONS=>CNS_A.   "'A' = 行+列多选
  C_LAYOUT-CWIDTH_OPT = ABAP_TRUE.             "优化列宽
  "C_LAYOUT-EDIT     = ABAP_TRUE.              "编辑（需要时打开）
ENDFORM.
```

#### FRM_SET_FIELDCAT（使用 MCR_FIELDCAT_SET 宏）

```abap
FORM FRM_SET_FIELDCAT TABLES T_FIELDCAT STRUCTURE LVC_S_FCAT.
  DATA: LS_FIELDCAT TYPE LVC_S_FCAT,
        LV_POS      TYPE I.

  DEFINE MCR_FIELDCAT_SET.
    LV_POS = LV_POS + 1.
    LS_FIELDCAT-COL_POS   = LV_POS.
    LS_FIELDCAT-FIELDNAME = '&1'.
    LS_FIELDCAT-COLTEXT   = &2.
    LS_FIELDCAT-REF_TABLE = '&3'.
    LS_FIELDCAT-REF_FIELD = '&4'.
    LS_FIELDCAT-EDIT      = &5.
    LS_FIELDCAT-OUTPUTLEN = &6.
    LS_FIELDCAT-KEY       = &7.
    LS_FIELDCAT-CHECKBOX  = &8.
    LS_FIELDCAT-NO_ZERO   = &9.
    LS_FIELDCAT-LZERO     = SPACE.
    LS_FIELDCAT-JUST      = ZIF_BC_CONS=>CNS_C.   "'C' = 居中
    LS_FIELDCAT-SCRTEXT_L = LS_FIELDCAT-COLTEXT.
    LS_FIELDCAT-SCRTEXT_M = LS_FIELDCAT-COLTEXT.
    LS_FIELDCAT-SCRTEXT_S = LS_FIELDCAT-COLTEXT.
    IF LS_FIELDCAT-REF_TABLE EQ CNS_SAPCE.
      CLEAR: LS_FIELDCAT-REF_TABLE, LS_FIELDCAT-REF_FIELD.
    ENDIF.
    "字段级特殊处理在此插入（如下拉、货币、小数位等）
    APPEND LS_FIELDCAT TO T_FIELDCAT.
    CLEAR LS_FIELDCAT.
  END-OF-DEFINITION.

  REFRESH T_FIELDCAT.

  MCR_FIELDCAT_SET:
    FIELD1  TEXT-001 SPACE SPACE SPACE 10 SPACE SPACE SPACE,
    FIELD2  TEXT-002 SPACE SPACE SPACE 20 SPACE SPACE SPACE.
  "第2,4参数=列标题(用文本元素TEXT-xxx), 3,4=参考表/字段, 5=EDIT, 6=OUTPUTLEN, 7=KEY, 8=CHECKBOX, 9=NO_ZERO
  "SPACE=false/不填, ABAP_TRUE=true
ENDFORM.
```

#### FRM_SHOW_ALV（带事件注册）

```abap
FORM FRM_SHOW_ALV TABLES T_DATA TYPE STANDARD TABLE
                  USING  U_T_FIELDCATALOG TYPE LVC_T_FCAT
                         U_T_SORT   TYPE LVC_T_SORT
                         U_S_LAYOUT TYPE LVC_S_LAYO.

  DATA: LS_VARIANT  LIKE DISVARIANT,
        LS_SETTING  TYPE LVC_S_GLAY,
        LT_EVENT    TYPE SLIS_T_EVENT.

  LS_VARIANT-REPORT = SY-REPID.

  "需要编辑时注册 DATA_CHANGED 事件
  IF 编辑条件.
    DATA: LS_EVT TYPE SLIS_ALV_EVENT.
    LS_EVT-NAME = 'DATA_CHANGED'.
    LS_EVT-FORM = 'FRM_DATA_CHANGED'.
    APPEND LS_EVT TO LT_EVENT.
    LS_SETTING-EDT_CLL_CB = ABAP_TRUE.   "立即触发
  ENDIF.

  CALL FUNCTION 'REUSE_ALV_GRID_DISPLAY_LVC'
    EXPORTING
      I_CALLBACK_PROGRAM       = SY-REPID
      I_CALLBACK_PF_STATUS_SET = CNS_ALV_STATUS  "'FRM_ALV_PF_STATUS'
      I_CALLBACK_USER_COMMAND  = CNS_ALV_COMAND  "'FRM_ALV_USER_COMMAND'
      I_SAVE                   = ZIF_BC_CONS=>CNS_A
      IS_VARIANT               = LS_VARIANT
      IT_SORT_LVC              = U_T_SORT[]
      IS_LAYOUT_LVC            = U_S_LAYOUT
      IT_FIELDCAT_LVC          = U_T_FIELDCATALOG[]
      IT_EVENTS                = LT_EVENT[]        "事件表
      I_GRID_SETTINGS          = LS_SETTING        "网格设置
    TABLES
      T_OUTTAB                 = T_DATA[]
    EXCEPTIONS
      PROGRAM_ERROR            = 1
      OTHERS                   = 2.
  IF SY-SUBRC NE 0.
    MESSAGE ID SY-MSGID TYPE SY-MSGTY NUMBER SY-MSGNO
      WITH SY-MSGV1 SY-MSGV2 SY-MSGV3 SY-MSGV4.
  ENDIF.
ENDFORM.
```

                                U_SELFIELD TYPE SLIS_SELFIELD.
  U_SELFIELD-REFRESH   = ABAP_TRUE.
  U_SELFIELD-COL_STABLE = ABAP_TRUE.
  U_SELFIELD-ROW_STABLE = ABAP_TRUE.

  ENDCASE.

### DATA_CHANGED 事件处理

```abap
FORM FRM_DATA_CHANGED USING UCL_DATA TYPE REF TO CL_ALV_CHANGED_DATA_PROTOCOL.
  DATA: LS_CELLS TYPE LVC_S_MODI.

  LOOP AT UCL_DATA->MT_MOD_CELLS INTO LS_CELLS.
    CLEAR GS_OUT.
    READ TABLE GT_OUT INTO GS_OUT INDEX LS_CELLS-ROW_ID.

    IF LS_CELLS-FIELDNAME = 'XX'.
      "特殊逻辑
    ELSE.
      ASSIGN COMPONENT LS_CELLS-FIELDNAME OF STRUCTURE GS_OUT
        TO FIELD-SYMBOL(<FV>).
      IF sy-subrc = 0.
        <FV> = LS_CELLS-VALUE.
      ENDIF.
    ENDIF.

    MODIFY GT_OUT FROM GS_OUT INDEX LS_CELLS-ROW_ID.
  ENDLOOP.
ENDFORM.
```

### 关键常量说明（来自 ZBCX_PUB_CONV_CONS / ZIF_BC_CONS）

| 常量 | 值 | 用途 |
|------|-----|------|
| `CNS_ALV_STATUS` | `'FRM_ALV_PF_STATUS'` | PF-STATUS 回调 FORM 名 |
| `CNS_ALV_COMAND` | `'FRM_ALV_USER_COMMAND'` | 工具栏按钮回调 FORM 名 |
| `CNS_ALV_GUI` | `'GUI_ALV'` | GUI 状态名（需在 SE41 创建） |
| `CNS_FD_SLBOX` | `'SLBOX'` | 选择框字段名（必须在 GTY_OUT 中有 SLBOX） |
| `CNS_SAPCE` | `' '` | 空字符串 |
| `ZIF_BC_CONS=>CNS_A` | `'A'` | ALV SEL_MODE 行+列多选 |
| `ZIF_BC_CONS=>CNS_C` | `'C'` | 文本居中 |
| `ZIF_BC_CONS=>CNS_I` | `'I'` | SIGN include |
| `ZIF_BC_CONS=>CNS_EQ` | `'EQ'` | OPTION equals |

### 注意事项

1. 按钮功能码（UCOMM）命名规范：以 `Z` 开头，如 `ZSAVE`、`ZGEN`、`ZADD`、`ZDEL`、`ZPRINT`，避免与 SAP 标准功能码冲突
2. `SLBOX` 字段必须在 `GTY_OUT` 中声明，类型 `TYPE C`
3. 文本元素（TEXT-001 等）用于列标题，不要硬编码中文在代码里
4. `CNS_ALV_GUI` 对应的 GUI 状态需在 SE41 创建，否则 `SET PF-STATUS` 会运行时崩溃
5. 不涉及编辑的报表无需注册 `DATA_CHANGED` 事件和 `LCL_EVENT_RECEIVER` 类
6. 涉及编辑的报表需在 `FRM_SET_FIELDCAT` 中对可编辑字段设 `EDIT = ABAP_TRUE`
7. `ZBCX_PUB_CONV_CONS` 包含共享常量，必须 INCLUDE
